# 3GPP Specification Downloader

Инструмент для скачивания 3GPP спецификаций конкретных релизов/версий с
**3gpp.org** (ZIP-архивы) и **etsi.org** (PDF, fallback). Предоставляет CLI
и веб-форму.

## Возможности

- Выбор спецификации по номеру (например `29.274`)
- Автоматическое получение списка доступных версий с 3gpp.org
- Скачивание с 3gpp.org (ZIP → извлечение .doc/.pdf) и etsi.org (PDF)
- Fallback: если 3gpp.org не нашёл — пробует etsi.org и наоборот
- Веб-интерфейс: выбор из списка популярных спецификаций + версии из списка
- CLI: скачивание по номеру и версии одной командой

## Установка

```bash
pip install -r requirements.txt
```

## Использование — CLI

```bash
# Скачать TS 29.274 v15.3.0 (источник: 3gpp.org, fallback etsi.org)
python cli.py download 29.274 15.3.0

# Только с 3gpp.org
python cli.py download 29.274 15.3.0 -s 3gpp

# Только с etsi.org
python cli.py download 29.274 15.3.0 -s etsi

# Скачать в другую папку, без распаковки ZIP
python cli.py download 29.274 15.3.0 -d ./specs --no-extract

# Список доступных версий для спецификации
python cli.py list 29.274

# Список популярных спецификаций
python cli.py common
```

## Использование — веб-форма

```bash
python cli.py web           # http://127.0.0.1:8090
python cli.py web -p 8080   # другой порт
python cli.py web -d ./specs  # другая папка загрузки
```

Откройте `http://127.0.0.1:8090` в браузере:

1. Введите номер спецификации (или кликните по строке в таблице «Популярные»)
2. Выберите версию из выпадающего списка (загружается с 3gpp.org)
3. Выберите источник (оба / 3gpp / etsi)
4. Нажмите «Скачать» → появится ссылка на файл

## Примечание

Сайты 3GPP/ETSI иногда меняют структуру URL. Если инструмент перестал
находить файлы — используйте `python cli.py list <spec>`, чтобы увидеть
актуальные версии, и обновите `core/specs.py` при необходимости.

## Проверка существования версии

Инструмент проверяет, существует ли запрошенная версия, прежде чем скачивать:

1. Пробует прямой URL на 3gpp.org (`29274-f30.zip` для 29.274 v15.3.0)
2. Если прямой URL вернул ошибку (404/403/любой не-200) — запрашивает
   листинг каталога спецификации и ищет точную версию по имени файла
3. Если версии нет в листинге — возвращает понятную ошибку со списком
   доступных версий:
   ```
   version 20.0.0 does not exist on 3gpp.org (direct URL returned 403);
   available versions: 0.1.0, ..., 19.5.0, 19.6.0  (total 160)
   ```
4. Существующие версии, у которых прямой URL дал ошибку, корректно
   скачиваются через листинг (fallback по имени файла)
5. При `prefer=both` и неудаче на обоих источниках возвращается сводная
   ошибка с деталями от 3gpp.org и etsi.org

Проверка работает и для `etsi.org`: перебираются все варианты URL, затем
проверяется листинг каталога ETSI. ETSI публикует только "published" версии
(обычно подмножество версий 3gpp.org), поэтому версия может отсутствовать
на ETSI, даже если есть на 3gpp.org:

```
version 15.3.0 does not exist on etsi.org (only published versions are
available); available: 8.0.0, ..., 19.5.0, 19.6.0  (total 111)
```

## Как формируются URL

### 3gpp.org (основной)

```
https://www.3gpp.org/ftp/Specs/archive/29_series/29.274/29274-f30.zip
```

- `29_series` — каталог серии (по первой части номера)
- `29274` — номер спецификации без точки
- `f30` — код версии: `f` = Release 15, `30` = v15.3.0

Маппинг релиза в букву: Rel-4=`a`, Rel-5=`b`, ... Rel-15=`f`, Rel-16=`g`,
Rel-17=`h`, Rel-18=`i`, Rel-19=`j`.

Внутри ZIP — документ (.doc/.pdf). Инструмент автоматически извлекает его.

### etsi.org (fallback)

```
https://www.etsi.org/deliver/etsi_ts/129200_129299/129274/16.04.00_60/ts_129274v160400p.pdf
```

- `129200_129299` — диапазон серии по номеру спецификации
  (для `274` → `129200_129299`, для `401` → `123400_123499`)
- `129274` — номер с префиксом серии `1` (серия 29 → `129`)
- `16.04.00_60` — папка версии (двузначные компоненты)
- `ts_129274v160400p.pdf` — PDF-файл
